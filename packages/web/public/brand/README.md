live in the repository root, in `IMAGENS LOGO/`, and are never edited:

`master/source/` also keeps an earlier delivery on a LIGHT studio backdrop
(`logo-oficial-lockup.jpg`, `logo-oficial-horizontal.jpg`,
`logos-oficiais-sheet.jpg`). They are originals and stay, but they are not the
current master.

**Do not redraw or cut out the mark.** Depth, chrome light and neon pulses are
rendered on top of the master at run time; its pixels stay as delivered.

## Why there is no cut-out file

The masters sit on dark backdrops, so the backdrop is removed at paint time and
no transparent copy is stored. `BrandSymbol` clears it with an SVG
`feColorMatrix` alpha from the pixels' own brightness (backdrop max channel
~25-46, drop shadow darker, chrome from ~55). At display size the WebGL hero
uses a connectivity matte instead, so dark grooves inside the chrome are never
mistaken for backdrop.

The earlier cut-outs (`trindatron-symbol.png`, `-{512,256,128,64}.png`,
`-512.webp`) were extracted from the light-backdrop `logo-oficial-lockup.jpg`.
The grey halo and torn edges they showed on dark surfaces were remnants of that
light backdrop. They were derivatives generated by earlier automated work
(commit 42ddc59), not masters, and have been removed.

## Honest limits

**The symbol belongs on dark surfaces.** Its backdrop is part of the render;
on a light surface the paint-time matte has nothing to separate it from.

**The wordmark is black.** It is painted into the artwork on a light
backdrop and cannot be recoloured without repainting the art. So the lockup
used on dark surfaces pairs the real symbol with the wordmark set in type
(Inter 600, 0.15em tracking) — see `BrandLockup` in
`src/components/brand/master.tsx`. The complete original wordmark appears on
the light plate, where it belongs.

## Colour comes from the mark

The interface palette is read off the artwork: cyan `#00c2d4` as the accent,
with a chrome ramp (`--chrome-high` / `--chrome-mid` / `--chrome-low`,
composed into `--chrome-ramp` in `src/app/globals.css`) for display type and
hairlines. The earlier purple `#7c3aed` was a placeholder chosen before the
logo existed and has been removed.

## In the product

- `src/components/brand/master.tsx` — `BrandSymbol`, `BrandLockup`,
  `BrandLockupPlate`. The real artwork. Use these on brand surfaces.
- `src/components/brand/trinity-mark.tsx` — a flat `currentColor` glyph the
  app uses at 14–20px in chat bubbles and the sidebar. The master is a
  photographic render: at 14px, tinted, it would be mud, and it cannot
  inherit a text colour. The two coexist deliberately.

## Legacy files

The `trindatron-*.svg` files in this directory are the pre-logo geometric
stand-in, kept only because `trinity-mark.tsx` still derives from the same
coordinates. They are not the brand.
